# 汉字/英语/拼音录音功能方案

## 1. 需求

为学习端（孩子端）的「汉字、英语、拼音」三类卡片增加录音答题：

1. 卡片提供「录音」按钮，点击开始录音，再次点击结束录音。
2. 识别录音内容，与题目比对。
3. 给出「是否正确」的结果反馈。

成语（`idiom_card`）已实现录音答题（复用浏览器 `SpeechRecognition`），本方案为汉字、英语、拼音三类做同类扩展。

## 2. 现状

三类均为「卡片题」、无作答（点击「下一个」即完成）：

| 类型 | question_type       | question_stem                            | 附加信息                                                                       |
| ---- | ------------------- | ---------------------------------------- | ------------------------------------------------------------------------------ |
| 汉字 | `character_card`    | 单个汉字（如「根」）                     | `question_pinyin` 逐字拼音                                                     |
| 英语 | `english_word_card` | 单词/词组（如「apple」「good morning」） | 无                                                                             |
| 拼音 | `pinyin_card`       | 拼音（如「b」「bā」「zhi」）             | 后端快照含 `pinyin_category`、原始 `pinyin`（前端 `SessionQuestion` 暂不返回） |

## 3. 方案选型

复用成语录音答题的实现思路：

- **识别**：浏览器内置 `SpeechRecognition`（Web Speech API），纯前端、零后端、零存储。
- **识别语言**：英语 `en-US`，汉字/拼音 `zh-CN`（复用现有 `getSpeechLanguage`）。
- **判分**：
  - 汉字、英语：**纯前端**字符串归一化比对（与成语一致）。
  - 拼音：识别文本是汉字/字母混合，「文本 → 拼音」转换需拼音库，**推荐后端 `pypinyin` 辅助**（后端已有该依赖）。

## 4. 各类型识别与判分规则

### 4.1 汉字（character）

- 识别语言：`zh-CN`。
- 判分：`normalize(识别文本) == normalize(question_stem)`。
- 多音字容错（可选增强）：将识别文本转拼音与 `question_pinyin` 比对。

### 4.2 英语（englishWord）

- 识别语言：`en-US`。
- 判分：`normalize(识别文本，转小写、去标点) == normalize(question_stem)`。
- 多词词组（如「good morning」）同样按整体归一化比对。

### 4.3 拼音（pinyin）——难点

拼音卡片展示的是拼音符号（声母/韵母/整体认读音节，可选带声调）。孩子读的是其「发音」，而识别引擎返回的可能是汉字（如读「b」→ 识别「波」）或字母，因此**不能直接与拼音符号做字符串比对**。

**判分思路**：为每个拼音生成标准「读音拼音」（去声调），把识别文本转拼音（去声调）后与其比对。

- 声母（initial）：声母不能独立成音，读音为其「呼读音」，需映射表：

| 声母 | 读音 | 声母 | 读音 | 声母 | 读音 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| b    | bo   | j    | ji   | z    | zi   |
| p    | po   | q    | qi   | c    | ci   |
| m    | mo   | x    | xi   | s    | si   |
| f    | fo   | zh   | zhi  | y    | yi   |
| d    | de   | ch   | chi  | w    | wu   |
| t    | te   | sh   | shi  |      |      |
| n    | ne   | r    | ri   |      |      |
| l    | le   |      |      |      |      |

- 单韵母（single_final）/ 韵母（final）/ 整体认读音节（whole_syllable）：读音即拼音本身（去声调）。

**判分流程**：`pypinyin(识别文本)` 去声调 → 与「读音拼音」比对。

## 5. 前端方案

1. 新增常量 `RECORDABLE_CARD_QUESTION_TYPES = {character_card, english_word_card, idiom_card, pinyin_card}`（成语已含）。
2. 录音按钮展示条件由「仅 idiom_card」改为「RECORDABLE_CARD_QUESTION_TYPES 命中」；古诗（poem_card）、国学（classic_card）内容较长，仅朗读不录音判分。
3. 识别语言按 `content_type`：`englishWord → en-US`，其余 `zh-CN`（复用 `getSpeechLanguage`）。
4. 判分：
   - 汉字/英语：前端 `normalizeTranscript` 比对。
   - 拼音：调用后端判分接口（见第 6 节），返回 `is_correct`。
5. 结果展示复用现有 `speech-feedback`（绿色「读对了！」/ 红色「再试一次 + 正确答案」）。
6. 状态与清理：复用 `isRecording`、`recognitionRef`、`speechResult`；切题/卸载时停止录音。

## 6. 后端方案（拼音判分辅助）

### 6.1 出题时生成「读音拼音」

在 `_build_pinyin_question` 中，为拼音生成 `read_pinyin` 字段写入题目快照：

```python
INITIAL_READING = {"b": "bo", "p": "po", "m": "mo", "f": "fo",
                   "d": "de", "t": "te", "n": "ne", "l": "le",
                   "g": "ge", "k": "ke", "h": "he",
                   "j": "ji", "q": "qi", "x": "xi",
                   "zh": "zhi", "ch": "chi", "sh": "shi", "r": "ri",
                   "z": "zi", "c": "ci", "s": "si", "y": "yi", "w": "wu"}

def _read_pinyin(pinyin: str, category: str) -> str:
    base = _strip_tone(pinyin)
    if category == "initial":
        return INITIAL_READING.get(base, base)
    return base
```

### 6.2 判分接口（可选）

`POST /api/v1/children/{child_id}/sessions/{session_id}/questions/{question_id}/speech`

- 请求：`{ transcript: string }`。
- 处理：校验题目为 `pinyin_card`；`pypinyin(transcript)` 取声母韵母去声调；与题目 `read_pinyin` 比对。
- 响应：`{ is_correct: bool, read_pinyin: string, correct_answer: string }`。

### 6.3 数据兼容

- 新增 `read_pinyin` 字段仅用于判分，不影响现有拼音展示与作答。
- 若前端希望完全零后端，可改用前端拼音库（如 `pinyin-pro`）在本地做「识别文本 → 拼音」转换，但声母映射与多音字处理不如后端 `pypinyin` 一致。

## 7. 风险与限制

| 风险       | 说明                                      | 应对                         |
| ---------- | ----------------------------------------- | ---------------------------- |
| 浏览器支持 | SpeechRecognition 仅 Chrome/Edge 稳定     | 不支持时按钮禁用             |
| 联网依赖   | Chrome 识别走 Google 云                   | onerror 提示                 |
| 麦克风权限 | 需授权 + HTTPS/localhost                  | onerror 引导                 |
| 拼音识别难 | 单个声母/音节识别准确率低，返回汉字或字母 | 后端 pypinyin + 声母映射兜底 |
| 多音字     | 汉字/英语识别可能与标注拼音不一致         | 首版严格比对，后续拼音容错   |
| 儿童语音   | 童声/噪声可能误识别                       | 展示识别文本，家长可复核     |

## 8. 测试方案

### 8.1 前端

- 汉字/英语/拼音卡片渲染「录音」按钮；古诗/国学/算术不渲染。
- 点击「录音」→ `recognition.start` 且按钮变「停止」；再次点击 → `recognition.stop`。
- mock `onresult`，断言汉字/英语判分正确。
- 拼音卡片点击后调用后端判分接口（mock），断言结果展示。

### 8.2 后端

- `_read_pinyin`：声母映射、韵母/整体认读去声调。
- 判分接口：mock `pypinyin`，断言「波」→ 判「b」正确、「八」→ 判「bā」正确等。

## 9. 实施范围

- **首版**：前端扩展录音按钮到汉字/英语/拼音三类 + 汉字/英语前端判分；拼音判分接后端接口（或首版拼音仅做识别文本展示、暂不判分）。
- **后端**：新增 `read_pinyin` 字段与判分接口（拼音判分必需）。
