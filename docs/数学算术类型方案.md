# 数学算术类型方案

## 1. 文档说明

- 文档名称：数学算术类型方案
- 版本：V1.0
- 日期：2026-10-26
- 目的：在现有「儿童学习助手」基础上新增「算术」类型，说明前后端实现与数据存储方案

## 2. 需求

1. 管理端（家长端）：设置算术的**最小值**、**最大值**，勾选运算符（加、减、乘、除），确认保存。
2. 答题端（孩子端）：根据家长设置的范围与运算符**随机出题**，孩子**手动输入答案**并判分。

## 3. 现状分析

当前系统内容类型为：`character`（汉字）、`classic`（国学）、`poem`（古诗）、`idiom`（成语）、`englishWord`（英语）。

算术与现有类型的关键差异：

| 维度     | 现有类型                      | 算术                      |
| -------- | ----------------------------- | ------------------------- |
| 数据来源 | 内容条目（`contents/*.json`） | 规则参数（范围 + 运算符） |
| 出题方式 | 从内容库抽样                  | 按设置即时随机生成        |
| 作答方式 | 卡片（点击下一个，不判分）    | 输入答案（判分）          |
| 存储     | 每个内容一条记录              | 每个孩子一条设置记录      |

因此算术需要：新增一种「规则驱动」的内容类型、新增按孩子维度的算术设置存储、新增「数字输入」作答交互，并复用 `submit_answer` 判分。

## 4. 总体设计决策

1. 新增内容类型枚举 `math`（算术），但不落 `contents/*.json`（无具体内容条目）。
2. 新增按孩子维度的算术设置，独立存储到 `data/math_settings.json`（每个孩子一条有效记录）。
3. 新增题型 `math_arithmetic`，孩子端使用「数字输入框」作答，复用 `POST .../sessions/{session_id}/answers` 判分。
4. 管理端新增「算术设置」入口；答题端类型选择新增「算术」。
5. 算术题计入正确率（`answered_questions` / `correct_questions` / `accuracy_rate`）。

## 5. 数据存储方案

### 5.1 math_settings.json 结构

每个孩子最多一条有效记录（软删除后保留历史）。采用 upsert 语义。

```json
[
  {
    "id": "uuid",
    "child_id": "uuid",
    "min_value": 1,
    "max_value": 20,
    "operators": ["add", "subtract", "multiply", "divide"],
    "status": 1,
    "created_at": "2026-10-26T10:00:00Z",
    "updated_at": "2026-10-26T10:00:00Z",
    "deleted_at": null,
    "is_deleted": 0
  }
]
```

| 字段                                              | 类型      | 可空 | 默认    | 说明                                         |
| ------------------------------------------------- | --------- | ---- | ------- | -------------------------------------------- |
| id                                                | str       | 否   | UUID    | 主键                                         |
| child_id                                          | str       | 否   | 无      | 关联孩子                                     |
| min_value                                         | int       | 否   | 0       | 最小值，≥ 0                                  |
| max_value                                         | int       | 否   | 20      | 最大值，> min_value                          |
| operators                                         | list[str] | 否   | ["add"] | 非空子集：add / subtract / multiply / divide |
| status                                            | int       | 否   | 1       | 是否启用算术，0/1                            |
| created_at / updated_at / deleted_at / is_deleted | -         | -    | -       | 通用时间与软删除字段                         |

运算符枚举与符号：`add` `+`、`subtract` `-`、`multiply` `×`、`divide` `÷`。

约束：`0 ≤ min_value < max_value`；`operators` 非空且每个值合法；同一孩子仅一条有效设置。

### 5.2 会话题目快照

算术题 `content_id` 为 `null`，`content_snapshot` 保存本次出题参数：

```json
{
  "id": "uuid",
  "session_id": "uuid",
  "content_id": null,
  "content_type": "math",
  "question_type": "math_arithmetic",
  "question_stem": "3 + 5 = ?",
  "question_options": [],
  "correct_answer": "8",
  "answer_explanation": "",
  "question_order": 1,
  "content_snapshot": {
    "title": "3 + 5 = ?",
    "min_value": 1,
    "max_value": 20,
    "operator": "add",
    "operand_a": 3,
    "operand_b": 5
  }
}
```

## 6. 后端方案

### 6.1 模型（backend/app/models.py）

- `ContentType` 增加 `"math"`。
- 新增 `MathOperator = Literal["add", "subtract", "multiply", "divide"]`。
- 新增 `MathSettingsUpsert`（`min_value`、`max_value`、`operators`、`status`）与 `MathSettings`（含 `id`/`child_id`/时间/软删除字段）。

### 6.2 服务层（parent_service.py）

- `get_math_settings(parent_id, child_id) -> MathSettings | None`
- `upsert_math_settings(parent_id, child_id, payload) -> MathSettings`
- 校验：`min_value >= max_value` 或 `operators` 为空 → `ValueError`（映射为 `42207`）。

### 6.3 接口（api/routers/math.py）

- `GET /api/v1/children/{child_id}/math-settings`：返回设置；未设置时 `data` 为 `null`。
- `PUT /api/v1/children/{child_id}/math-settings`：upsert。

### 6.4 出题规则（learning_service.py）

`start_session` 中，选中类型含 `math` 时读取设置并即时生成题目：

| 运算符   | 生成规则                                             | 结果                |
| -------- | ---------------------------------------------------- | ------------------- |
| add      | a, b ∈ [min, max]                                    | a + b               |
| subtract | a, b ∈ [min, max]，a < b 则交换                      | a - b（非负）       |
| multiply | a, b ∈ [min, max]                                    | a × b               |
| divide   | b ∈ [max(1, min), max]，商 q ∈ [min, max]，a = b × q | q（整除、非负整数） |

`question_stem = "{a} {符号} {b} = ?"`，`correct_answer = str(result)`。

题量：仅 `math` → 生成 `question_count` 题；`math` 与内容类型混合 → 按选中类型数均分（`math` 至少 1 题），不足由算术题补齐。

### 6.5 判分

复用 `submit_answer`，`math_arithmetic` 走数字校验：非整数 → `42208`；`int(user_answer) == int(correct_answer)`。

### 6.6 错误码

| 错误码 | 含义                                         |
| ------ | -------------------------------------------- |
| 40407  | 算术设置不存在                               |
| 42207  | 算术设置不合法（min ≥ max、运算符为空/非法） |
| 42208  | 答案必须是整数                               |

## 7. 前端方案

- `types/api.ts`：`ContentType` 增加 `"math"`；新增 `MathOperator`、`MathSettings`、`MathSettingsPayload`。
- `api/math.ts`（新增）：`getMathSettings`、`updateMathSettings`。
- `ParentDashboard.tsx`：新增「算术设置」标签页（最小值 / 最大值 / 运算符复选 / 启用 / 保存）；学习规则 `default_content_types` 使用含「算术」的 `LEARNING_TYPE_OPTIONS`。
- `ChildLearning.tsx`：类型选择增加「算术」；`math_arithmetic` 题目渲染数字输入框（`InputNumber`）+「提交答案」，复用 `submitAnswer` 与反馈条。

## 8. 测试方案

- 后端：`test_math_settings.py`（获取/upsert/非法参数）；`test_child_learning_api.py`（算术出题、判分、非整数 42208、无设置 40407）。
- 前端：`ParentDashboard.test.tsx`（保存算术设置）；`ChildLearning.test.tsx`（输入数字作答）。

## 9. 不改动项与约定

- 既有五种内容类型及卡片作答方式保持不变。
- `list_contents` / 「学习内容管理」不处理 `math`（无内容条目）。
- `stats_weak_contents` 不包含算术（无 `content_id`），为预期行为。
