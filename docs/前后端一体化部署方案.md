# 前后端一体化部署方案

## 1. 目标

将前端（React + Vite）构建产物放入后端 `app/web` 目录，由 FastAPI 直接托管静态资源与 SPA 页面，实现「运行后端即可访问前端界面」的单端口部署方式。

## 2. 参考实现

本方案参考 `HAIAs智能医生助理/rcp` 项目的做法：

- 前端 `vite.config.ts` 通过 `build.outDir` 把构建产物直接输出到 `backend/app/web`；
- 后端 `main.py` 挂载 `web/assets` 静态目录，并注册 SPA fallback，把非 API 路径统一返回 `index.html`。

## 3. 前端改动

### 3.1 构建输出目录

`frontend/vite.config.ts`：

- `build.outDir` 指向 `../backend/app/web`，`emptyOutDir: true`；
- `server.proxy` 把开发态的 `/api` 代理到 `http://127.0.0.1:8000`。

### 3.2 API 地址

`frontend/src/api/client.ts` 的 `API_BASE` 默认改为相对路径 `/api/v1`：

- 托管模式：前端与后端同源，相对路径直接命中后端接口；
- 开发模式：由 Vite dev server 将 `/api` 代理到后端。

仍可通过 `VITE_API_BASE` 环境变量覆盖。

## 4. 后端改动

`backend/app/main.py`：

- 若 `app/web/index.html` 存在，挂载 `web/assets` 静态目录；
- 注册 `/` 与 `/{spa_path:path}` 路由，非 `api/docs` 等保留前缀的路径统一返回 `index.html`（SPA 回退），并做路径穿越防护。

## 5. 使用方式

### 5.1 构建前端

```powershell
cd frontend
npm install
npm run build
```

构建产物会输出到 `backend/app/web`。

### 5.2 运行后端

```powershell
cd backend
C:/Users/Administrator/me12/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

访问 http://127.0.0.1:8000/ 即可打开前端界面。

## 6. 开发模式

开发期可保持前后端分离：

1. 启动后端（8000 端口）；
2. 启动前端 `npm run dev`（5173 端口）；
3. 前端通过 Vite 代理把 `/api` 转发到后端。

## 7. 注意事项

- `backend/app/web` 为构建产物，可由 `.gitignore` 忽略，不入库；
- 后端已注册的 API 路由（`/api/v1/*`、`/health`）优先级高于 SPA fallback，不受影响；
- SPA fallback 对 `api`、`docs`、`redoc`、`openapi.json` 前缀做保留，避免遮蔽后端接口与文档。
