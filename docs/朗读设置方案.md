# 朗读设置方案

## 1. 需求

管理端（家长端）新增「朗读设置」，为「汉字、国学、古诗、成语、英语」五类卡片**分别设置朗读语速**；孩子端朗读时按卡片类型应用对应语速。

## 2. 数据方案

- 存储文件：`backend/data/read_settings.json`（JSON 列表，每个孩子一条记录，模式同 `math_settings.json` / `pinyin_settings.json`）。
- 数据维度：按 `child_id` 存储，每个孩子独立一份。
- 字段（每类型一个语速，均为 `float`，范围 `0.1 ~ 2.0`，默认 `0.8`）：

| 字段             | 含义     | 默认 | 范围    |
| ---------------- | -------- | ---- | ------- |
| `character_rate` | 汉字     | 0.8  | 0.1~2.0 |
| `classic_rate`   | 国学     | 0.8  | 0.1~2.0 |
| `poem_rate`      | 古诗     | 0.8  | 0.1~2.0 |
| `idiom_rate`     | 成语     | 0.8  | 0.1~2.0 |
| `english_rate`   | 英语     | 0.8  | 0.1~2.0 |
| `status`         | 是否启用 | 1    | 0/1     |

- 新建孩子时自动初始化默认朗读设置（`_init_child_defaults`）。

## 3. 后端方案

- `models.py`：新增 `ReadingSettingsUpsert`（写入载荷）与 `ReadingSettings`（存储模型）。
- `parent_service.py`：新增 `get_reading_settings` / `upsert_reading_settings`，并在新建孩子时写入默认值；常量 `DEFAULT_READ_RATE = 0.8`。
- 新增路由 `api/routers/reading.py`：
  - `GET /children/{child_id}/reading-settings` 查询朗读设置（无记录返回 `null`）。
  - `PUT /children/{child_id}/reading-settings` 保存朗读设置（upsert）。
- `main.py` 注册该路由。

## 4. 前端方案

### 4.1 家长端

- `ParentDashboard` 新增「朗读设置」Tab：5 个语速滑块（`Slider`，`min=0.1 max=2.0 step=0.1`）+「启用朗读」开关 + 保存按钮。
- 新增 `api/reading.ts`：`getReadingSettings` / `updateReadingSettings`。

### 4.2 孩子端

- 孩子端加载朗读设置，朗读时按卡片 `content_type` 取对应语速。
- `speech.ts` 新增纯函数 `getReadRate(contentType, settings)`，设置缺失时回退默认 `0.8`。
- 朗读逻辑：`utterance.rate = getReadRate(question.content_type, readSettings)`，替换原先写死的 `0.3`。

## 5. 语速语义

| 倍率    | 效果                       |
| ------- | -------------------------- |
| 0.1~0.8 | 慢速（默认 0.8，适合跟读） |
| 1.0     | 正常语速                   |
| 1.2~2.0 | 较快                       |

> 语速由浏览器 Web Speech API 的 `SpeechSynthesisUtterance.rate` 控制，实际效果受系统/浏览器语音包影响，属已知限制。

## 6. 兼容与默认

- 旧数据无 `read_settings.json` 时：首次保存自动创建；查询返回 `null`，前端/孩子端回退默认 `0.8`。
- 孩子端朗读设置加载失败时，回退默认语速 `0.8`，不影响朗读功能。
