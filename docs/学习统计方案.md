# 学习统计方案（答题次数 / 错误次数 / 错误率）

## 1. 需求

1. 为「汉字、国学、古诗、成语、英语」五类内容统计每条内容的**答题次数、错误次数、错误率**。
2. 在家长端「学习内容管理」列表中对应条目展示。
3. 列表支持按**标题、答题次数、错误次数、错误率**排序。

## 2. 现状与统计口径

当前五类内容均为「卡片」模式（孩子查看后点「下一个」，无对错判定），因此数据中没有「错误」来源。

经确认，采用「**仅统计学习次数**」口径：

| 指标     | 口径                         | 说明                                      |
| -------- | ---------------------------- | ----------------------------------------- |
| 答题次数 | 学习次数（卡片被查看的次数） | 实时统计，有真实数据                      |
| 错误次数 | 0                            | 占位（卡片无对错判定）                    |
| 错误率   | 0                            | 占位（= 错误次数 / 答题次数，卡片恒为 0） |

## 3. 数据来源（数据存储）

不新增存储文件，统计在读取时实时计算。

数据来源：`data/sessions/session_questions.json`。

每条会话题目快照包含：`content_id`、`content_type`、`question_type`、`viewed_at`。

统计规则：

- 对某个 `content_id`，累加满足「`question_type ∈ CARD_QUESTION_TYPES` 且 `viewed_at` 非空」的题目记录数，即该内容的「答题次数（学习次数）」。
- `error_count = 0`、`error_rate = 0`（占位）。

## 4. 后端方案

- `parent_service._content_stats(child_id)`：读取 `session_questions`，按 `content_id` 聚合出 `{content_id: {learn_count, error_count, error_rate}}`。
- `parent_service.list_contents_with_stats(...)`：在 `list_contents` 的筛选基础上，计算统计、按 `sort_by`/`sort_order` 排序、分页，返回带 `learn_count/error_count/error_rate` 的内容字典。
- `contents.py` 的 `GET /children/{child_id}/contents` 新增查询参数：
  - `sort_by`：`title` / `learn_count` / `error_count` / `error_rate`
  - `sort_order`：`asc` / `desc`

## 5. 前端方案

- `types/api.ts`：`LearningContent` 增加 `learn_count`、`error_count`、`error_rate`。
- `api/contents.ts`：`listContents` 增加 `sort_by`、`sort_order` 参数。
- `ParentDashboard.tsx`：
  - 内容列表新增「答题次数、错误次数、错误率」列（错误率显示为百分比）。
  - 「标题、答题次数、错误次数、错误率」列开启 `sorter`，通过 `Table.onChange`（`extra.action === "sort"`）触发服务端排序并回传排序参数。

## 6. 说明

- 因卡片无对错判定，`错误次数`、`错误率` 恒为 0；排序能力仍保留，但该两列排序结果相等（稳定排序）。
- 若后续为卡片增加「记住 / 没记住」自评，只需在 `_content_stats` 中改用自评结果统计 `error_count`/`error_rate` 即可，存储结构与接口无需改动。

## 7. 清除统计

1. 管理端「学习内容管理」区新增「清除统计」按钮（未选择类型时禁用）。
2. 点击后弹确认，调用 `DELETE /api/v1/children/{child_id}/stats?content_type=xxx`。
3. 后端 `clear_content_stats`：对所选类型，取该孩子的有效内容 `content_id`，软删除 `session_questions.json` 中对应的题目快照（`is_deleted = 1`）。
4. 由于 `_content_stats` 只统计未删除快照，清除后该类型各内容「答题次数」归 0，后续新学习重新累计。
