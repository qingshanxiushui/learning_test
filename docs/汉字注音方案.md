# 汉字注音方案（汉字/国学/古诗/成语逐字标注拼音）

## 1. 需求

汉字、国学、古诗、成语四类内容出题时，在卡片上为**每个汉字上方标注拼音**（带声调），帮助孩子认读。

## 2. 现状

- 这四类均为「内容驱动 + 卡片」模式：`character_card`、`classic_card`、`poem_card`、`idiom_card`。
- 卡片 `question_stem` 目前只展示文本本身（汉字/诗句/成语等），无拼音标注。

## 3. 总体设计决策

1. 拼音**不落库、不新增存储**，出题时用 `pypinyin` 库**实时计算**。
2. 计算出的拼音以 `question_pinyin`（与 `question_stem` 逐字符对齐的字符串数组）写入会话题目快照 `session_questions.json`，随题目一起返回给前端。
3. 前端按「每个汉字上方拼音、下方汉字」渲染；非汉字（标点、换行、《》、·等）原样显示、不标拼音。
4. 拼音带声调（标准四声）。

## 4. 数据存储方案

- 不新增存储文件，也不改动既有内容结构。
- 会话题目快照新增一个字段 `question_pinyin`（`list[str]`），长度与 `question_stem` 一致：

```json
{
  "question_stem": "地大物博",
  "question_pinyin": ["dì", "dà", "wù", "bó"]
}
```

- 对齐规则：`question_pinyin[i]` 对应 `question_stem` 的第 `i` 个字符；汉字为带声调拼音，非汉字（含换行）为该字符本身。

## 5. 后端方案

- `requirements.txt`：新增 `pypinyin==0.55.0`。
- `learning_service.py`：
  - 新增 `_pinyin_annotation(text) -> list[str]`：按行调用 `pypinyin.pinyin(style=Style.TONE)`，返回与 `text` 逐字符对齐的拼音数组（换行单独保留）。
  - `_build_question` 对四类卡片（character/classic/poem/idiom）在题目中注入 `question_pinyin`。
  - `_build_math_question`、`_build_pinyin_question` 注入空数组 `question_pinyin: []`（该两类不需要标注）。
- `session_questions()` 不隐藏 `question_pinyin`（始终随题目返回）。

## 6. 前端方案

- `types/api.ts`：`SessionQuestion` 新增 `question_pinyin?: string[]`。
- `ChildLearning.tsx`：
  - 新增 `AnnotatedText` 组件：遍历 `question_stem` 逐字符渲染，有拼音的汉字渲染为「上拼音下汉字」的结构，换行渲染为 `<br>`。
  - 卡片题干：`question_pinyin` 非空时用 `AnnotatedText` 渲染，否则回退为纯文本。
- `index.css`：新增 `.annotated-text` / `.char-unit` / `.char-pinyin` / `.char-glyph` / `.char-plain` 样式，拼音用相对字号（约 0.42em）显示在汉字上方，随卡片字号缩放。

## 7. 测试方案

- 后端：新增 `test_card_questions_have_pinyin_annotation`，验证成语「地大物博」的 `question_pinyin == ["dì","dà","wù","bó"]`。
- 前端：新增「annotates pinyin above characters」用例，验证拼音与汉字同时渲染。

## 8. 说明与约定

- 多音字默认取 `pypinyin` 的首个读音（单字/成语场景足够；整句场景有轻微歧义，属可接受范围）。
- 拼音为实时计算，不随内容存储，后续若需人工修正读音，可再扩展为内容级覆盖配置。
