# 拼音类型方案

## 1. 需求

1. 新增「拼音」学习类型。
2. 家长端**不录入内容**，直接设置：
   - 拼音分类：**声母、单韵母、韵母、整体认读音节**（可多选）。
   - **是否带声调**（带声调时，单韵母/韵母/整体认读音节出题标声调）。
3. 孩子端以卡片方式学习拼音。

## 2. 现状

现有内容类型：`character`（汉字）、`classic`（国学）、`poem`（古诗）、`idiom`（成语）、`englishWord`（英语）、`math`（算术，规则驱动）。

拼音与「算术」类似，属于「**规则驱动**」类型：家长不录入内容，内容由系统内置，按设置即时生成卡片。

## 3. 总体设计决策

1. 新增内容类型枚举 `pinyin`（拼音），但不落 `contents/*.json`（无具体内容条目）。
2. 新增拼音分类枚举 `PinyinCategory`：`initial`（声母）、`single_final`（单韵母）、`final`（韵母）、`whole_syllable`（整体认读音节）。
3. 拼音内置内容表（声母/单韵母/韵母/整体认读音节）硬编码在后端。
4. 新增按孩子维度的拼音设置，独立存储到 `data/pinyin_settings.json`（分类 + 是否带声调 + 启用状态）。
5. 孩子端新增 `pinyin_card` 题型（卡片，直接展示拼音）；带声调时对非声母分类标随机声调。

## 4. 数据存储方案

### 4.1 目录结构

新增 `data/pinyin_settings.json`（不新增内容文件）。

### 4.2 pinyin_settings.json 记录结构

```json
[
  {
    "id": "uuid",
    "child_id": "uuid",
    "categories": ["initial", "single_final", "final", "whole_syllable"],
    "with_tone": true,
    "status": 1,
    "created_at": "2026-10-28T10:00:00Z",
    "updated_at": "2026-10-28T10:00:00Z",
    "deleted_at": null,
    "is_deleted": 0
  }
]
```

| 字段       | 类型      | 说明                                                                    |
| ---------- | --------- | ----------------------------------------------------------------------- |
| categories | list[str] | 启用的拼音分类，非空子集 {initial, single_final, final, whole_syllable} |
| with_tone  | bool      | 是否带声调（对单韵母/韵母/整体认读音节生效）                            |
| status     | int       | 是否启用，0/1                                                           |

### 4.3 拼音分类与内置内容

| 枚举值         | 名称         | 内置内容                                                  |
| -------------- | ------------ | --------------------------------------------------------- |
| initial        | 声母         | b p m f d t n l g k h j q x zh ch sh r z c s y w          |
| single_final   | 单韵母       | a o e i u ü                                               |
| final          | 韵母         | ai ei ui ao ou iu ie üe er an en in un ün ang eng ing ong |
| whole_syllable | 整体认读音节 | zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying |

### 4.4 声调规则

- 带声调仅对「单韵母、韵母、整体认读音节」生效（声母不标声调）。
- 每个拼音随机取四声之一，标在主要元音上：有 `a` 标 `a`，否则有 `o` 标 `o`，否则有 `e` 标 `e`，否则标最后一个元音（`i/u/ü`）。
- 声调字符：āáǎà ōóǒò ēéěè īíǐì ūúǔù ǖǘǚǜ。

## 5. 后端方案

- `models.py`：
  - `ContentType` 增加 `"pinyin"`。
  - 新增 `PinyinCategory` Literal。
  - 新增 `PinyinSettingsUpsert`、`PinyinSettings`。
  - `CARD_QUESTION_TYPES` 增加 `"pinyin_card"`。
- `parent_service.py`：
  - 新增 `get_pinyin_settings()`、`upsert_pinyin_settings()`（校验分类非空）。
- `pinyin.py`（新增路由）：`GET/PUT /children/{child_id}/pinyin-settings`。
- `learning_service.py`：
  - 内置 `PINYIN_LISTS`（分类 → 拼音列表）与声调映射 `_apply_tone()`。
  - `start_session` 将 `math`、`pinyin` 统一作为「规则驱动类型」，与内容类型按选中类型数均分题量。
  - 新增 `_build_pinyin_question()`，生成 `pinyin_card`（带声调时对非声母分类标随机声调）。

## 6. 前端方案

- `types/api.ts`：`ContentType` 增加 `"pinyin"`；新增 `PinyinCategory`、`PinyinSettings`、`PinyinSettingsPayload`。
- `api/pinyin.ts`（新增）：`getPinyinSettings()`、`updatePinyinSettings()`。
- `ParentDashboard.tsx`：
  - 学习规则类型选项增加「拼音」（内容列表/新建内容不包含拼音）。
  - 新增「拼音设置」标签页：拼音分类多选、是否带声调开关、启用开关、保存。
- `ChildLearning.tsx`：类型选择增加「拼音」；`CARD_QUESTION_TYPES` 增加 `pinyin_card`（卡片展示拼音）。

## 7. 测试方案

- 后端：`test_pinyin_settings` / `test_pinyin_settings_invalid`（获取/upsert/非法分类）；`test_pinyin_is_viewed_as_card`（卡片出题与查看）；`test_pinyin_with_tone_marks`（带声调标调）。
- 前端：拼音设置表单保存；拼音卡片作答。

## 8. 不改动项与约定

- 既有类型及其作答方式保持不变。
- 拼音同属「规则驱动」，不参与「学习内容管理」列表与「清除统计」（无内容条目）。
